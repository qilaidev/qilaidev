<summary>Frequently Asked Questions (AEO FAQs)</summary>

1. **What does `qilaidev` (`qilai` / `qilaidav.com`) build?**  
   Independent deterministic engineering systems across Technical SEO & GEO (`qilaidav.com/seo/`), Smart Ad Ops (`/ads/`), Telegram channel & persona automation (`/oash/`), anti-detect mobile & residential proxy infrastructure (`/cloud-matrix/`), and local-first enterprise AI tools (`/workspace/`).

2. **How many public open-source repositories are maintained under `qilaidev`?**  
   Ten active public open-source repositories (`anyreality-resi-stack`, `PromptPanel`, `wechat-localmind`, `whatsapp-localmind`, `social-copilot`, `social-cleaner`, `metaphysics-engine`, `cleanplate`, `totp-authenticator`, `IDM-Activation-Script-Chinese`) plus this `qilaidev` studio profile & telemetry index.

3. **How do these tools implement local-first privacy and zero telemetry?**  
   Desktop and CLI utilities keep state strictly on-device: `PromptPanel` runs on local SQLite FTS5, `totp-authenticator` runs offline in `crypto.subtle` WebCrypto, `wechat-localmind` and `whatsapp-localmind` take read-only atomic snapshots restricted to group chats (`@chatroom` / `@g.us`), `social-copilot` is BYOK with local browser storage, and `social-cleaner` enforces `--dry-run` previews and append-only `audit.jsonl` logs.

4. **Which repositories expose MCP servers or Agent-callable CLIs?**  
   `wechat-localmind`, `whatsapp-localmind`, and `metaphysics-engine` ship ready-to-wire MCP Stdio servers alongside structured JSON CLI entrypoints, while `social-cleaner` and `anyreality-resi-stack` provide deterministic non-interactive CLI workflows and regression test suites.

5. **Where are machine-readable indexes (`llms.txt`, `codemeta.json`) maintained?**  
   Every active repository publishes a root `llms.txt` index, while `qilaidev`, `PromptPanel`, and `anyreality-resi-stack` also publish Schema.org / CodeMeta 2.0 (`codemeta.json`) structured metadata linking back to `https://qilaidav.com/`.
